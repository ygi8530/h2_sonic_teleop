## 2. 핵심 규칙

1. **정책 출력 = 명령(목표각)**, 실제 움직임은 몸의 PD가 만든다 (시뮬=우리 수식, 실물=로봇 보드 500 Hz).
2. **몸의 state가 매 스텝 ②로 되돌아와야 루프가 닫힌다** — 로봇이 밀려도 균형을 잡는 이유이자,
   실물에서 state 출처를 센서로 갈아끼워야 하는 이유.
3. **wbc_h12는 화살표 흐름 밖** — 실행되지 않고, ①③이 기동 시 파일만 꺼내 읽는 부품 창고.
4. **GMR은 이 그림에 없다** — 오프라인 모션파일 공장(훈련·평가·재생 pkl 제작)일 뿐,
   라이브 teleop은 사람 신호 직통 (teleop/smpl 입구는 리타게팅을 신경망이 내장 학습).

## 3. 정책의 3모드 입구 (universal token)

```
                 ┌─ [g1]     로봇 관절 참조모션(pkl)   ← GMR로 만든 파일 필요 (모션 재생용)
동결 encoder ────├─ [teleop] 사람 VR 3점 (손목×2+가슴) ← 라이브, 다리는 자동 균형
                 └─ [smpl]   사람 SMPL 24관절 날것     ← 라이브, 전신(발 포함) 모방
```
러너가 모드 선택 스칼라+원핫으로 입구를 고른다 (`--mode smpl|teleop`).
